# About repository
- Includes scripts that helps with 3D modelling in either Blender, 3ds Max or Maya (mainly Blender and 3ds Max)
# About tools
## Extrude Tool
- Blender tool for extruding edges simulating the UI and functionality from 3ds Max to aid 3ds Max users in extruding edges in Blender
## Pivot Placer Tool
- 3ds Max tool for transfering (copying) pivots from the source objects to the target objects
- Useful for automatically place pivots from higher LOD to lower LOD of the same object in 3ds Max
- The current version of this tool assume the low LOD objects are in the same position as the high LOD objects in 3d space. It currently only copies pivots.
